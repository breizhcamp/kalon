# Histoire
En tant qu'user, je dois pouvoir lister les événements disponibles.

Les événements doivent inclure les informations suivantes :
- Identifiant unique
- Nom de l'événement
- Date de début
- Date de fin
- Site web
- Lieu

# Règles d'acceptation
- Les évènements doivent être listés par ordre de date de début décroissante (du plus proche au plus lointain).
