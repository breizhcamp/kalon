# Histoire
En tant qu'admin, je dois pouvoir supprimer un événement.


# Règles d'acceptation
- L'admin peut supprimer un événement en fournissant son identifiant.
- Si l'identifiant n'existe pas, un message d'erreur approprié doit être retourné.
- La base de données doit être mise à jour de l'évènement supprimé.
