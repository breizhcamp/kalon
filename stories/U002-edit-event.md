# Histoire
En tant qu'admin, je dois pouvoir modifier un événement.

Les propriétés modifiables d'un événement sont les suivantes :
- nom
- date de début
- date de fin
- site web (optionnel)
- adresse (optionnel)

# Règles d'acceptation
- L'admin peut modifier un événement en fournissant les informations requises.
- Le système doit valider que la date de fin est postérieure à la date de début.
- Une fois l'événement créé, il doit mis à jour dans la base de données.
